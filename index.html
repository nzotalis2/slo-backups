slo-backups

slo-backups is a personal tool. It runs on one server that I operate and uploads nightly backups of a personal research database to my own Google Drive, using rclone.

It uses Google's drive.file permission, which lets it see and manage only the files it creates itself: it uploads backup files, lists them, and deletes its own old copies. It cannot see anything else in the Drive.

It is not offered to anyone else, and only its owner signs in to it.
